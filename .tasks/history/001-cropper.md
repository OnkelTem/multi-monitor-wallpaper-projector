# 001 — Интерактивный кадрирователь (crop.py) и реорганизация wallpaper.py

## Мотивация

При подготовке изображений для панорамы нужно вручную кадрировать их под aspect ratio плоскости `panorama` из Blender-сцены. Текущий `prepare_panorama_image()` делает cover-fit автоматически, но часто обрезает важную часть изображения (верхушки зданий). Нужен удобный инструмент для полуавтоматического кадрирования с клавиатурным управлением.

## Файловая структура (на примере `123.jpg`)

```
текущая_директория/
├── 123.jpg                 # исходная картинка
├── scene.json              # геометрия сцены
├── config.json             # конфиг (выходные размеры мониторов)
├── 123/                    # рабочая директория картинки
│   ├── crop.json           # координаты области кадрирования
│   ├── source.jpg          # обрезанное изображение под aspect панорамы
│   ├── left.jpg            # результат wallpaper.py
│   ├── center.jpg
│   └── right.jpg
└── .tasks/
    └── active/
        └── 001-cropper.md  # этот файл
```

Скрипты устанавливаются глобально, а `scene.json` и `config.json` лежат в текущей рабочей директории (откуда запускается команда).

## 1. Новый скрипт `crop.py`

### Назначение

Интерактивный кадрирователь с клавиатурным управлением. Показывает изображение в окне, накладывает рамку с заблокированным aspect ratio панорамы, позволяет клавишами двигать и изменять рамку, сохраняет результат.

### Интерфейс

```
python crop.py scene.json <image>
```

Параметры:
- `scene.json` — путь к файлу сцены (для чтения aspect ratio панорамы)
- `<image>` — путь к исходному изображению

### Что делает

1. Загружает `scene.json`, извлекает `panorama` quad, вычисляет `pano_width / pano_height` (через `get_quad_size`).
2. Загружает изображение `<image>`.
3. Показывает в окне OpenCV.
4. Рисует **зелёную рамку** с aspect ratio панорамы, изначально по центру.

### Управление клавишами

| Клавиша | Действие |
|---|---|
| `← ↑ ↓ →` | Сдвиг рамки на 10px |
| `Shift + ← ↑ ↓ →` | Сдвиг рамки на 100px |
| `+` / `=` | Увеличить размер рамки (меньше кадрирования) |
| `-` / `_` | Уменьшить размер рамки (больше кадрирования) |
| `r` | Сбросить рамку в центр, размер по умолчанию |
| `Enter` | Применить, сохранить, закрыть окно |
| `Esc` | Закрыть без сохранения |

Рамка **всегда сохраняет aspect ratio панорамы**. Изменяется только её положение и размер.

### Сохранение

При `Enter`:
1. Проверить, что рамка не выходит за границы изображения.
2. Создать директорию по имени исходного файла (без расширения): `{dirname}/`.
3. Сохранить `{dirname}/crop.json`:
   ```json
   { "x": 100, "y": 200, "width": 4000, "height": 740 }
   ```
4. Вырезать область из изображения (`image[y:y+h, x:x+w]`).
5. Сохранить как `{dirname}/source.jpg` (JPEG quality 95).

При `Esc` — выйти без сохранения, ничего не трогать.

## 2. Изменения в `wallpaper.py`

### Что меняется

**Входной путь (prepare_panorama_image → main):**
- В `main()`, после загрузки исходного изображения `img = cv2.imread(image_file)`: проверить, существует ли `{source_name}/source.jpg`.
- Если существует — использовать его как панорамное изображение вместо исходного файла (`pano_img = cv2.imread(...source.jpg)`).
- Если не существует — использовать исходный файл как сейчас (с cover-fit).

**Выходной путь (get_output_path):**
- Заменить `output_dir = os.path.join("dist", source_name)` на `output_dir = source_name`.
- Удалить строку `os.makedirs("dist", ...)` — директория картинки уже создана crop.py.
- Файлы сохраняются как `{source_name}/left.jpg`, `{source_name}/center.jpg`, `{source_name}/right.jpg`.

### Что НЕ меняется

- `scene.json` — без изменений
- `config.json` — без изменений
- `blender-scene-export.py` — без изменений
- `apply-kde-wallpapers.py` — без изменений (он принимает путь к директории, теперь это будет `{source_name}/`)
- Внутренняя логика `render_monitor()`, `build_world_grid()`, `vertices_to_quad()`, `get_quad_size()` — без изменений

### CLI

Без изменений:
```bash
python wallpaper.py scene.json config.json 123.jpg
```

## 3. Начальный размер рамки

При открытии изображения рамка ставится по центру. Начальный размер:
- Высота = в зависимости от aspect_ratio, вычисленного из scene.json
- Ширина = 100%
